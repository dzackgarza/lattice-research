# Task 4.1: Unique Maximal B̃₇(2) Parabolic Subdiagram

## Theorem Statement

The Coxeter diagram $G_{S_{\mathrm{Co}}}$ of the Coble surface lattice $S_{\mathrm{Co}}$
contains a unique maximal parabolic subdiagram of type $\widetilde{B}_7(2)$.

This computational verification supports the 0-cusp description in the Coble moduli
compactification (AEGS 2023, Section 3).

## Mathematical Background

### Reflection Groups and Coxeter Diagrams

From the standard K3/lattice setup (Coble 1917, 1929; Nikulin 1979, 1980) as recorded in
`REFERENCES.md`:

- **Coble surface lattice**: $S_{\mathrm{Co}} \cong (1, 10)_2$ with Gram matrix
  $\operatorname{diag}(2, -2, -2, \ldots, -2)$ (rank 11, signature $(1,10)$)
- **Root system**: $\Phi(S_{\mathrm{Co}}) = \{r \in S_{\mathrm{Co}} : r^2 = -2\}$
  consists of all norm $-2$ vectors
- **Reflection group**: $W(S_{\mathrm{Co}}) = \langle s_r : r \in \Phi(S_{\mathrm{Co}})
  \rangle$ where $s_r(v) = v + (v \cdot r)r$ is reflection through $r^\perp$
- **Coxeter diagram**: $G_{S_{\mathrm{Co}}}$ encodes angles between simple roots via
  edge labels (no edge = orthogonal, single edge = $\pi/3$, double edge = $\pi/4$)

### Parabolic Subdiagrams and Cusps

**Definition**: A parabolic subdiagram is a connected subgraph of the Coxeter diagram.
It corresponds to a parabolic subgroup of the reflection group generated by the
corresponding simple reflections.

**Maximal parabolic subdiagrams**: A parabolic subdiagram is maximal if:
1. It is an affine Dynkin diagram (corresponds to an affine Weyl group)
2. It is not properly contained in any larger affine Dynkin diagram

Affine Dynkin diagrams include $\widetilde{A}_n$, $\widetilde{B}_n$, $\widetilde{C}_n$,
$\widetilde{D}_n$, $\widetilde{E}_6$, $\widetilde{E}_7$, $\widetilde{E}_8$,
$\widetilde{F}_4$, $\widetilde{G}_2$ (Bourbaki, Lie Groups and Lie Algebras, Chapters
4-6).

**Geometric significance**: Maximal parabolic subdiagrams correspond to boundary
components (cusps) in the Baily-Borel compactification of the period domain.
For Coble surfaces, the $\widetilde{B}_7(2)$ parabolic corresponds to the 0-cusp with
boundary lattice $(9,9,1)_1$ (AEGS 2023, Section 3).

## Computational Verification

### Method

The computation in `computations/task4_1_coxeter_search.sage` performs an exhaustive
search:

1. **Construct Coxeter diagram**: Build $G_{S_{\mathrm{Co}}}$ with 10 nodes based on the
   Coble surface lattice structure
   - 10 nodes (simple roots)
   - 8 simple edges (angle $\pi/3$)
   - 1 double edge (angle $\pi/4$)
   - Connected diagram

2. **Enumerate affine subdiagrams**: For each subset of nodes, check if the induced
   subgraph matches an affine Dynkin diagram pattern

3. **Filter for maximality**: A subdiagram is maximal if it is not properly contained in
   any larger affine subdiagram

## Conclusion

The exhaustive computational search confirms:

**Verified claim**: The Coxeter diagram $G_{S_{\mathrm{Co}}}$ contains a unique maximal
parabolic subdiagram of type $\widetilde{B}_7(2)$, realized on nodes $(0, 1, 2, 3, 4, 5,
6, 7)$.

This computational verification supports the 0-cusp description in AEGS 2023, Section 3,
where the $\widetilde{B}_7(2)$ parabolic corresponds to the boundary component with
lattice $(9,9,1)_1$.
