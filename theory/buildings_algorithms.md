Explains the algorithms step by step and maps them to `src/external/buildings.sage`.

## Setup and Conventions

A **lattice** L is an even non-degenerate integral quadratic form on a free abelian group.
The bilinear form is written (x,y); the Gram matrix G(L) = ((xᵢ,xⱼ)).

Key lattice building blocks used throughout:

```
U:  Gram matrix [[0,1],[1,0]]                     (hyperbolic plane)
Aₙ: negative definite root lattice
⟨d⟩: rank-1 lattice generated by x with x²=d
L(m): L with quadratic form multiplied by m       e.g. U(2) has Gram [[0,2],[2,0]]
```

The **discriminant group** D(L) = L∨/L carries a ℚ/2ℤ-valued quadratic form q_L
inherited from L⊗ℚ. It classifies the genus of L.

The **divisor** div(x) of 0≠x∈L is the positive generator of the ideal (x,L)⊂ℤ.
The **primitive part** x* = x/div(x) ∈ L∨.

**Subgroups of O(L):**
- O⁺(L): elements of positive spinor norm (= kernel of sn_ℝ : O(L⊗ℝ) → ℝ/(ℝ*)²)
- Õ(L) = ker(O(L) → O(D(L))): the **stable orthogonal group** (acts trivially on D(L))
- Ō(L) = O_𝒜(L): elements whose image in O(D(L)) lies in subgroup 𝒜

A split maximal lattice has the form L' = 2U ⊕ L'₀; maximal means D(L') has no
nontrivial totally isotropic subgroup.

## §2: Orbits of Non-Isotropic Vectors

These algorithms answer: given v₁, v₂ ∈ L⊗ℚ non-isotropic, does g∈Γ exist with gv₁=v₂?

### Algorithm 2.1 (definite perpendicular complement)

**Hypothesis:** v₁⊥ is definite (so K = w⊥ ⊂ L is a positive/negative definite lattice).

**Idea:** Every element g∈O(L) mapping v₁↦v₂ decomposes as φ⊕ψ on ⟨w⟩⊕K,
where φ: w₁↦w₂ is forced and ψ: K₁→K₂ ranges over all isometries.
Since K is definite, Iso(K₁,K₂) is finite and computable (Fincke-Pohst / Plesken-Souvignier).

**Steps:**
1. Rescale vᵢ to wᵢ = cᵢvᵢ ∈ L (cᵢ minimal positive rational).
2. Quick invariant checks: if v₁²≠v₂² or c₁≠c₂, return inequivalent.
3. Compute Kᵢ = wᵢ⊥ ⊂ L via Smith normal form of ŵᵢ = wᵢᵀG(L).
   The columns q₂,…,qₙ of Q(ŵᵢ) form a basis for Kᵢ.
   By Smith normal form theory (d₂=…=dₙ=0), this Kᵢ is primitive in L.
4. Build embedding ιᵢ = (wᵢ | kᵢ₁ | … | kᵢ,ₙ₋₁): the change-of-basis matrix.
5. For each ψ ∈ Iso(K₁,K₂): set θ = ι₂∘(φ⊕ψ)∘ι₁⁻¹.
   Check θ ∈ Γ (integer matrix, correct discriminant action, correct spinor norm).
   If yes: return equivalent.
6. Return inequivalent.

### Algorithm 2.2 / 2.3 (indefinite perpendicular complement)

**Hypothesis:** v₁⊥ is indefinite and O(L)→O(D(L)) is surjective.

Since Kᵢ = wᵢ⊥ is now indefinite, one cannot enumerate Iso(K₁,K₂) directly.
Instead, use **Theorem 2.3 (Kneser-Nikulin genus criterion)**:

> If t₊≥1, t₋≥1, t₊+t₋≥3, and t₊+t₋ ≥ 2+l(q), then the genus of a lattice
> with signature (t₊,t₋) and discriminant form q contains exactly one class,
> and O(L)→O(D(L)) is surjective.

So K₁≅K₂ iff their signatures and discriminant forms agree (a finite check).
The search over ψ reduces to a search over Iso(q_{K₁}, q_{K₂}), the finite group
of isomorphisms of discriminant forms (not the full lattice isometry group).

**Algorithm 2.3** is a coordinate-level restatement of 2.2. Key additions:
- αᵢ := wᵢ²/|wᵢ²|  (sign of the vector, used for the Smith normal form of ⟨wᵢ⟩)
- The λᵢ matrices convert between L-coordinates and D(⟨wᵢ⟩)⊕D(Kᵢ)-coordinates.
- Hᵢ = image of L in D(⟨wᵢ⟩)⊕D(Kᵢ) (the "glue" subgroup from the inclusion ⟨wᵢ⟩⊕Kᵢ⊂L)
- Condition: the isomorphism φ⊕ψ must preserve Hᵢ and its action on D(L) must lie in 𝒜.

**Lemma 2.4:** If K₁ represents both ±2, then v₁∼_{O_𝒜(L)} v₂ ⟺ v₁∼_{SO_𝒜⁺(L)} v₂.
This is because the (-2)-reflection σ_v ∈ Õ(K₁) has determinant -1 and spinor norm -1,
so composing ψ with σ_v corrects both simultaneously.

## §3: Tits Buildings and Isotropic Subspaces

The **Tits building** ℬ(G) of a subgroup G ⊂ O⁺(L⊗ℚ) (with L of signature (2,n)) is the
bipartite graph whose nodes are:
- **lines** (black): G-orbits of totally isotropic lines ℓ ⊂ L⊗ℚ  (= 0-cusps of BB compactification)
- **planes** (white): G-orbits of totally isotropic planes Π ⊂ L⊗ℚ  (= 1-cusps)

with an edge [ℓ]—[Π] when some g∈G maps ℓ into Π.

**Connection to Baily-Borel:** By Theorem 1.5, the BB compactification F_L(Γ)* decomposes as
F_L(Γ) ⊔ ⊔_{Π} C_Π ⊔ ⊔_{ℓ} Q_ℓ
where C_Π are modular curves (1-cusps) and Q_ℓ are points (0-cusps). The incidence
Q_ℓ ∈ C̄_Π corresponds exactly to the edge [ℓ]—[Π] in ℬ(Γ).

### Algorithm 3.2: Building of O⁺(L') for maximal L'

**Hypothesis:** L' is a split maximal lattice of signature (2,n), n≥2.

The key fact (Attwell-Duval): two totally isotropic sublattices E₁, E₂ ⊂ L' are in
the same O⁺(L')-orbit iff E₁⊥/E₁ ≅ E₂⊥/E₂ as lattices.

**For lines (0-cusps):** All primitive isotropic vectors in a maximal lattice are
O⁺(L')-equivalent — there is exactly one orbit. So ℬ(O⁺(L')) has a single line node.

**For planes (1-cusps):** The orbits of totally isotropic planes correspond to classes
in the genus of the (0,n-2)-signature lattice with discriminant form D(L').
- Compute gen(0, n-2, D(L')) using the genus enumeration algorithm.
- Each class L₀ in this genus gives one plane-orbit [Π_{L₀}].
- The canonical basis S(L₀) for L'≅2U⊕L₀ provides the representative plane Π = ⟨x₁,x₃⟩.

**Incidence:** Every plane contains a unique (up to O⁺(L')-equivalence) line;
the building is a star: all planes connect to the single line node.
(Figure 1 in the paper shows this "spider" graph.)

### Algorithm 3.3: Computing τ(x,y) — the element sending x↦y

**Hypothesis:** L' = U⊕L₁ split maximal, x,y ∈ L' primitive isotropic.

Uses the identification 2U ≅ M₂(ℤ) via (x₁,x₂,x₃,x₄) ↦ [[x₃,-x₂],[x₁,x₄]],
where the quadratic form on M₂(ℤ) is 2·det.

The SL(2,ℤ)×SL(2,ℤ) action is (A,B)·X = AXB⁻¹, giving the embedding θ(A,B) ∈ O⁺(2U).
This is `BigGp.SL_emb_left(A)` and `BigGp.SL_emb_right(B)` in the code.

**Steps:**
1. Use Smith normal form of ι(x) ∈ M₂(ℤ) to find (A,B) diagonalizing x.
   Let g(x) = θ(A,B); this maps x into L₁ (zeroing out the first two coordinates).
2. Compute x' = g(x)x and y' = g(y)y (now both in L₁ ⊂ L').
3. Find u', v' ∈ L₁ with (x',u') = (y',v') = 1 (Euclidean algorithm / Bézout).
4. Return τ(x,y) = g(y)⁻¹ · t(e,-v') · t(f,x'-y') · t(e,u') · g(x).

This is `SubGp_A2t.eichler_equiv(x,y)` in the code, where `red_L1` implements step 1
(the Smith normal form reduction to L₁).

**Why it works:** The composition t(e,u')·g(x) maps x to e (the first basis vector);
t(f,x'-y') translates e₁' to e₃' within 2U; t(e,-v')·g(y)⁻¹ maps y' back to y.
This is the "Eichler criterion" proof (GHS09, Proposition 3.3) made explicit.

### Algorithm 3.1: Building of G₁ from G₂

**Setup:** G₁ ⊂ G₂ ⊂ O⁺(L⊗ℚ) with [G₂:G₁] < ∞.
Given ℬ(G₂) = (𝒩₂, ℰ₂), compute ℬ(G₁) = (𝒩₁, ℰ₁).

**Phase 1 — Identify orbits of nodes (step 3):**

Let 𝒢 = {gᵢ} be a transversal for G₂/G₁.
For each node [E] ∈ 𝒩₂, the set 𝒢·[E] = {[gᵢE]} gives candidate G₁-orbit representatives.
Two candidates gᵢE and gⱼE are G₁-equivalent iff there exists g∈G₁ with g(gᵢE) = gⱼE,
i.e., gⱼ⁻¹ggᵢ stabilizes E under G₂, i.e., some l_k·gⱼ·gᵢ⁻¹ ∈ G₁ for l_k in
the transversal Stab_{G₁}(gⱼE) \ Stab_{G₂}(gⱼE).

In the code:
- `make_left_cosets()` computes 𝒢 = G₂/G₁ (BFS from identity using BigGp.gens)
- `identify_bc_e()` does this identification for lines (0-cusps)
- `identify_bc_E()` does it for planes (1-cusps)
- `in_gp(x)` tests whether x ∈ G₁ (the membership oracle for the subgroup)

**Phase 2 — Identify incidence edges (step 4):**

For edge [ℓ]—[Π] in ℬ(G₁): we need some g∈G₁ with g(ℓ') ⊂ Π, where ℓ' is
a G₂-representative for [ℓ]. By Lemma 3.10, we only need to test ℓ' ∈ 𝒥·X
where:
- X = {e₁} (the canonical line inside the canonical plane Π = ⟨e₁,e₃⟩)
- 𝒥 = transversal for Γ(N) \ SL(2,ℤ) acting on Π via θ (see below)

The test is: does there exist y ∈ 𝒥·X and u ∈ Stab_{G₁}(ℓ') \ Stab_{G₂}(ℓ')
such that u·τ(y,ℓ') ∈ G₁?

In the code:
- `iso_classes_in_E(e1,e2)` computes 𝒥·e₁ (the Γ(N)\SL(2,ℤ) orbit of e₁ in Π)
- `line_plane_incid(e1,e2,gk,u)` tests the incidence condition above
- `incid_rels()` runs the full incidence computation for all (line,plane) pairs
- `building()` runs the full pipeline: cosets → lines → planes → incidence

### Lemma 3.10: The congruence level N

**This is the key lemma for generalizing to other lattices.**

Let L ⊂ L' be a maximal overlattice. Choose M > 0 with L'(M) ⊂ L.

> **The congruence level** N is defined as the exponent of L∨/L'(M).

Then:
1. SL(2,ℤ) ⊂ Stab_{O⁺(L')}(Π) for any totally isotropic plane Π.
2. Γ(N) ⊂ Stab_{Õ⁺(L)}(Π) — the principal congruence subgroup acts trivially on Π.
3. The Γ(N)\SL(2,ℤ) cosets of e₁ in Π give representatives for all Stab_{Õ⁺(L)}(Π)-orbits
   of isotropic lines in Π.

**Why:** Γ(N) acts trivially on L∨/L'(M) by definition, hence on L∨/L,
hence Γ(N) ⊂ Õ(L). Combined with SL(2,ℤ) acting transitively on isotropic
vectors of Π, this means Γ(N)\SL(2,ℤ) is a complete set of orbit representatives.

**Concrete computation of N:**
- L' = maximal overlattice of L (unique up to isomorphism by Lemma 3.3)
- M = exponent of L'/L (the smallest M with L'(M) ⊂ L)
- Then L'(M) ⊂ L ⊂ L' ⊂ L∨ ⊂ (L'(M))∨ = (1/M)·L'
- N = exponent of L∨/L'(M) = exponent of the discriminant group D(L) times M

**In practice:** for a 2-elementary lattice (D(L) = (ℤ/2)^k), the exponent is 2, so N=2.
For L = 2U⊕A₂ (which is already maximal), N = exponent of D(A₂) = exponent of (ℤ/3)² = 3,
and Γ(3) is used. But in `SubGp_A2t.ellg = Ell(6)`, the code uses N=6 instead of 3.
This is because A₂ is not split maximal: the actual L' enclosing 2U⊕A₂ in the A₂
case has a larger N due to the overlattice structure, giving N=6 as a safe (larger)
choice. For U⊕U(2)⊕A₂ the code also uses Ell(6); this is consistent since
2U⊕A₂ is the enclosing group anyway.

**For T_En = U⊕U(2)⊕E₈(2):**
- D(T_En) = (ℤ/2)^10, exponent = 2
- Maximal overlattice L' = 2U⊕E₈ (the unique unimodular overlattice)
- M = 2, N = exponent of T_En∨/L'(2) = 2
- Use Ell(2), giving |SL(2,ℤ)/Γ(2)| = 6 cosets to check per plane

### Algorithm 3.4: Building of G₂ from G₁

**Direction is reversed from 3.1:** given ℬ(G₁), find ℬ(G₂) for G₁ ⊂ G₂.

Motivation: if G₂ = O_𝒜⁺(L) and one cannot apply 3.2 directly (because L is not
maximal), compute ℬ(Õ⁺(L)) via 3.1 first, then "coarsen" it to ℬ(G₂) via 3.4.

**Steps:**
1. Let ℋ = transversal for G₁\G₂.
2. For each h∈ℋ and pair ([E₁],[E₂]) in ℬ(G₁):
   - Find ĝ∈O⁺(L') with ĝ(hE₁) = E₂ (using τ from Algorithm 3.3).
   - Compute transversal 𝒥 for Stab_{O⁺(L')}(hE₁)\Stab_{G₁}(hE₁).
   - If ĝ·𝒥 ∩ G₁ ≠ ∅, identify [E₁] and [E₂] in ℬ(G₂).

This "coarsening" merges nodes that G₂ identifies but G₁ did not.

## Generator Sets in buildings.sage

### BigGp = O⁺(2U⊕A₂)

Generators constructed in `BigGp.make_gens()`:

**Eichler transvections** t(e,a): for isotropic e∈L and a∈e⊥, the map
  v ↦ v - (a,v)e + (e,v)a - ½(a,a)(e,v)e
These generate Õ⁺(L) when a ranges over L₁ and e ∈ {e₁, f₁} (cf. Lemma 3.6).
In the 6×6 matrix representation: `BigGp.make_eichler(e,a)`.

**Reflections** σ_v: v ↦ v - 2(v,w)/(w,w)·w for non-isotropic w.
Used to generate the A₂ factor's orthogonal group (4 reflections v₁..v₄).
In the code: `BigGp.make_reflection(v)`.

**SL(2,ℤ) embeddings:** The two copies of U contribute two commuting SL(2,ℤ) factors.
`BigGp.SL_emb_left(A)` = θ(A,I) and `BigGp.SL_emb_right(B)` = θ(I,B) from eq.(12).
These act only on the first 4 coordinates (the 2U part), fixing A₂.

**Diagram automorphism jay:** permutes the two A₂ simple roots, corresponding to
the Z/2 outer automorphism of A₂. In matrix form: fixes e₁,f₁,e₂,f₂ and swaps w₁,w₂ with sign.

### Stabilizer generators

`BigGp.make_gens_stab_e()` = generators for Stab_{O⁺(L)}(e₁) = O⁺(L₁) ⋉ U(e₁)
  where L₁ = U⊕A₂ and U(e₁) is the unipotent radical generated by t(e₁,v).
  (Lemma 3.7)

`BigGp.make_gens_stab_E()` = generators for Stab_{O⁺(L)}(⟨e₁,e₃⟩) = Γ^J(L) ⋉ O⁺(A₂)
  (the Jacobi group semidirect product; Lemma 3.8)

### Membership test in_gp(x)

For `SubGp_A2t` (Õ⁺(2U⊕A₂)):
- u₃ = (0,0,0,0,-2/3,1/3) is a generator of D(A₂) in L∨
- x ∈ Õ(L) iff x·u₃ ≡ u₃ mod L, i.e., x·u₃ - u₃ ∈ L (integer vector)
  This checks that x acts trivially on D(L) = A₂∨/A₂.

For `SubGp_GK` (Õ⁺(2U⊕⟨-6⟩⊕⟨-2⟩)):
- Embeds L via θ: (2U⊕⟨-6⟩⊕⟨-2⟩) → (2U⊕A₂) via the overlattice map from Example 4.3
- Checks: (1) θ⁻¹xθ is an integer matrix (x preserves L), and
           (2) it fixes both generators of D(L) (acts trivially on discriminant group)

For `SubGp_UU2A2t` (Õ⁺(U⊕U(2)⊕A₂)):
- θ scales the (3,3) entry by 2 (embedding U(2) into the second U factor)
- Dual vectors: u_d1=(0,0,½,0,0,0), u_d2=(0,0,0,½,0,0) for U(2); w_d for A₂
- x ∈ Õ(L) iff z=θ⁻¹xθ is integral and zud₁≡ud₁, zud₂≡ud₂, zwd≡wd mod L

For `SubGp_UUmA2t` (Õ⁺(U⊕U(m)⊕A₂)):
- Generalization: θ[3,3]=m, dual vectors use 1/m, uses Ell(N) with user-supplied N

## §4 Examples and What the Code Computes

### Example 4.2: L = 2U⊕A₂

L is already maximal (A₂ is unique in its genus). So ℬ(O⁺(L)) has exactly:
- 1 line orbit (all primitive isotropic vectors equivalent)
- 1 plane orbit (one class in gen(0,0,q_{A₂}))
- 1 edge

For Õ⁺(L): index |O⁺(L):Õ⁺(L)| = 2, transversal {I, g₂} where g₂ swaps the A₂
simple roots. Both cosets give the same line and plane orbits (no splitting).
Result: ℬ(Õ⁺(2U⊕A₂)) = 1 line, 1 plane, 1 edge (Figure 3 in paper).

```sage
H = SubGp_A2t()
H.building()    # fast: < 1 second
```

### Example 4.4: L = 2U⊕⟨-6⟩⊕⟨-2⟩

Maximal overlattice L' = 2U⊕A₂ via the map (x₅,x₆) ↦ (-2x₅, x₅+x₆).
Index |O⁺(L'):Õ⁺(L)| is computable from this embedding.
Result: ℬ(Õ⁺(L)) has 2 lines, 2 planes (Figure 4). O⁺(L) doesn't further identify them.

```sage
H = SubGp_GK()
H.building()
```

### Example 4.5: L = 2U(2)⊕A₂

Index |O⁺(2U⊕A₂):Õ⁺(2U(2)⊕A₂)| = 1080. The intermediate tower
  Õ⁺(2U(2)⊕A₂) ⊂ Õ⁺(U⊕U(2)⊕A₂) ⊂ Õ⁺(2U⊕A₂) ⊂ O⁺(2U⊕A₂)
  of indices 20, 27, 2 can be used to speed up the coset enumeration (Remark 2).
Result: more complex building (Figure 5 in paper, not reproduced here).

```sage
H = SubGp_U2U2A2t()
H.building()    # takes hours; use intermediate tower for speedup
```
