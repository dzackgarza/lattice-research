## Complete classification of virtually abelian symmetry groups

**Source:** Brandhorst 2025 (arXiv:2507.20743)

### Main Theorem

**Theorem 1:** A hyperbolic lattice L of rank ≥3 has a virtually solvable symmetry group Aut(D_L) if and only if it belongs to an explicit list of **360 lattices**:

1. **118 lattices** with finite Aut(D_L) (Nikulin-Vinberg classification), rank ≤19
2. **194 lattices** with elementary parabolic type (Borcherds lattices), rank ≤26
3. **48 lattices** with elementary hyperbolic type

**Corollary 2 (K3 surfaces):** Aut(X) is virtually solvable iff either ρ(X)≤2, or Pic(X) belongs to an explicit list of **359 lattices** of rank ≥3. If so, rank of maximal abelian subgroup ≤8.

### Definitions

**Symmetry group:** Aut(D_L) := O⁺(L)/W(L) where W(L) is the Weyl group (generated by reflections in (-2)-roots)

**Elementary group:** Has a finite orbit in hyperbolic space H_L

**Three types of elementary groups:**
1. **Elliptic:** Fixed point in interior of H_L (finite)
2. **Parabolic:** One fixed point in boundary ∂H_L (zero entropy)
3. **Hyperbolic:** Two fixed points in ∂H_L (virtually cyclic)

### Algorithm for rank 3

**Input:** Oracle to determine if Aut(M) is finite or elementary hyperbolic for rank n-1 lattices

**Step 1:** Define H₁ = {[L_{a,b,c}] : -1≤a≤2, -1≤b≤c≤18, L_{a,b,c} hyperbolic}

**Gram matrix L_{a,b,c}:**
```
[[-2, a, b],
 [ a,-2, c],
 [ b, c,-2]]
```

**Justification (Nikulin):** If L has finite or elementary hyperbolic Aut(D_L), then ∃ 3 linearly independent roots δ₁,δ₂,δ₃ with -2 < δᵢ·δⱼ ≤ 18.

**Step 2:** Filter H₁ by checking oracle on each L_{a,b,c}

### Algorithm for rank 4

**Gram matrix L_{a,b,c,d,e,f}:**
```
[[-2, a, b, c],
 [ a,-2, d, e],
 [ b, d,-2, f],
 [ c, e, f,-2]]
```

**Similar filtering:** Check oracle on rank-3 sublattices

### Connection to other classifications

- **Nikulin-Vinberg (118 finite):** Lattices with finite Aut(D_L), rank ≤19
- **Brandhorst-Mezzedimi (194 parabolic):** Borcherds lattices with zero entropy
- **Yu (parabolic, K3 Picard):** Independent classification for K3 Picard lattices
- **Nikulin (hyperbolic):** Finiteness of rank n≥3 lattices with elementary hyperbolic Aut(D_L)

### Proof technique: Tits alternative

**Tits alternative:** Any finitely generated subgroup of isometries of hyperbolic lattice is either virtually solvable or contains a free non-abelian subgroup.

**Key insight:** Virtually solvable ⟺ virtually abelian ⟺ elementary (for hyperbolic isometry groups)

**Three cases:** Elliptic (finite), parabolic (zero entropy), hyperbolic (virtually cyclic)
