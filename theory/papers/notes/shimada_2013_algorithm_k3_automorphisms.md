## Algorithms for computing automorphism groups of K3 surfaces

**Source:** Shimada 2013 (arXiv:1304.7427)

### Main Algorithm

**Algorithm (main):** Computes finite set of generators of Im(φ_X: Aut(X) → O(S_X)) and closed fundamental domain F ⊂ Nef(X) under milder assumptions than previous work.

**Key innovation:** Works when S_X doesn't satisfy the strong conditions required by earlier Borcherds-based methods.

### Example 1: Picard number 3, infinite automorphism group

**Néron-Severi lattice S_X:** Gram matrix
```
M = [[-2, 0, 1],
     [ 0,-2, 1],
     [ 1, 1,-2]]
```

**Properties:**
- Picard number ρ(X) = 3
- Aut(X) infinite
- φ_X: Aut(X) → O(S_X) has finite kernel

**Computational result:** Explicit generators available (see paper for details)

### Example 2: Singular K3 with discriminant 11

**Transcendental lattice T_X:** Gram matrix
```
[[2, 1],
 [1, 6]]
```

**Properties:**
- Picard number ρ(X) = 20 (singular K3)
- disc T_X = 2·6 - 1² = 11
- φ_X injective
- Aut(X) always infinite for singular K3 (Shioda-Inose)

**Computational result:**
- Im(φ_X) generated by **767 elements** of O(S_X)
- Explicit 20×20 matrices available on author's webpage
- ≤347 smooth rational curves on X modulo Aut(X)

**Note:** Numbers 767 and 347 are not minimal.

### Standard transcendental lattices for singular K3

**General form:** Gram matrix
```
[[2a, b ],
 [b,  2c]]
```

**Constraint:** disc T_X = ac - b² ≡ 0 or 3 (mod 4) (since T_X is even)

**Known cases:**
- disc = 3, 4: Vinberg
- disc = 7: Ujikawa
- disc = 8: "usual" Borcherds method
- disc = 11: This paper (Example 2)

### Proof technique: Embedding into L₂₆

**Setup:** Embed S_X into even unimodular hyperbolic lattice L₂₆ of rank 26 (Borcherds' idea).

**Previous limitation:** Required S_X to satisfy strong conditions.

**This paper's contribution:** Milder assumptions on S_X, broader applicability.
