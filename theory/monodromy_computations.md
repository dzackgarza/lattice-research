# Monodromy Computation for Algebraic Families

This document surveys available tools for computing the **homological monodromy** of a
family f(x₁,...,xₙ, t) = 0 over a punctured disc Δ* = Δ \ {0}, where t is the disc
parameter.

The object of interest is the monodromy operator

  M ∈ Aut(Hₖ(F_{t₀}, ℤ))

for k = dim F_t, where F_{t₀} = V(f(·, t₀)) ⊂ ℂⁿ is the fiber over a basepoint.
Since π₁(Δ*, t₀) ≅ ℤ (generated by a single loop around 0), M is a single matrix.

---

## What "monodromy" means here

Given a loop γ: [0,1] → Δ* with γ(0) = γ(1) = t₀, analytic continuation of the
homology basis {γ₁,...,γ_{2g}} of F_{t₀} along γ returns a (generally different) basis
{M·γ₁,...,M·γ_{2g}}. The matrix M ∈ GL(H₁(F_{t₀},ℤ)) is the monodromy.

For an arbitrary loop t(θ) = t₀·e^{iθ} (θ ∈ [0,2π]), the period matrix of F_{t(θ)}
evolves as Ω(θ). After a full loop, Ω(2π) = Ω(0)·Mᵀ (since Ω_{ij} = ∫_{γⱼ} ωᵢ and
M acts on the γ_j). The monodromy M is symplectic: Mᵀ·J·M = J where J is the standard
symplectic form on H₁(F, ℤ).

## Approach 1: RiemannSurface parallel transport (curves, n=2)

**Scope**: Families of curves f(z, w, t) = 0 where the fiber is a smooth curve of
genus g.

**Key tools**:
- `sage.schemes.riemann_surfaces.riemann_surface.RiemannSurface`
- `RiemannSurface.period_matrix()` — numerical period matrix, certified via homotopy
  continuation (Bruin-Sijsling-Zotine [BSZ2019])
- `RiemannSurface.symplectic_isomorphisms(other)` — finds integer symplectic matrices M
  such that Ω(self) ≅ Ω(other)·M, using LLL reduction on the endomorphism algebra

**Strategy**: Discretize a loop t(θ) = ε·e^{iθ} into N steps. At each step k, construct
S_k = RiemannSurface(f(z, w, t_k)) and compute the period matrix Ω_k. Between consecutive
steps, find a local symplectic matrix M_k via `S_k.symplectic_isomorphisms(S_{k+1})`.
Compose: M = M_{N-1}·...·M_0.

In practice, if the steps are small enough that Ω_k and Ω_{k+1} are close, M_k ≈ I and
the LLL search terminates quickly.

**Simplified version** (single comparison): Since f(z, w, t₀) = f(z, w, t₀·e^{2πi}) as
polynomials (they are equal), S_before = RiemannSurface(f(z, w, t₀)) and S_after are
isomorphic. But their **homology bases** differ. The monodromy is:

  M = (symplectic matrix taking Ω_before → Ω_after)

obtained by computing Ω_after via parallel transport around the loop (evaluating
RiemannSurface at many intermediate t-values and chaining the symplectic isomorphisms),
then calling `S_before.symplectic_isomorphisms(S_after_transported)`.

**Existing method**: `RiemannSurface.monodromy_group()` already computes local monodromy
*as permutations of sheets* (topological monodromy of the covering f(z,w)=0 → ℂ_z). This
is NOT the same as the homological monodromy M ∈ Sp(2g, ℤ), but is a precursor: the
permutation monodromy generators determine the topology of the cover, from which the
Picard-Lefschetz formula (see §4) can be applied to extract the homological monodromy.

**Prototype code skeleton**:
```python
from sage.schemes.riemann_surfaces.riemann_surface import RiemannSurface
from sage.all import QQ, CC, exp, pi, I, Matrix

def family_monodromy_curve(f_xy_t, t0, eps=0.5, N=20, prec=100):
    """
    Compute the homological monodromy matrix of the family f(z,w,t)=0 over
    a small loop |t-0| = eps centered at the singularity t=0, based at t=t0.

    f_xy_t: polynomial in QQ[z, w, t]
    t0:     basepoint (complex number, |t0|=eps, not a critical value)
    N:      number of steps around the loop
    """
    R = f_xy_t.parent()
    z, w, t = R.gens()
    CC_prec = ComplexField(prec)
    t0_CC = CC_prec(t0)

    # Discretize the loop t(θ) = eps * exp(i*(arg(t0) + 2π*k/N))
    arg0 = t0_CC.argument()
    t_vals = [eps * exp(CC_prec(0, arg0 + 2*pi*k/N)) for k in range(N+1)]
    # t_vals[0] = t_vals[N] = t0 (up to floating point)

    def fiber_at(t_val):
        f_fixed = f_xy_t.subs({t: t_val})
        R2 = f_fixed.parent()
        return RiemannSurface(f_fixed, prec=prec)

    # Build period matrices along the loop
    surfaces = [fiber_at(tv) for tv in t_vals]

    # Chain symplectic isomorphisms between consecutive fibers
    M_total = Matrix.identity(ZZ, 2 * surfaces[0].genus)
    for k in range(N):
        isos = surfaces[k].symplectic_isomorphisms(surfaces[k+1])
        if not isos:
            raise ValueError(f"No symplectic isomorphism found at step {k}; increase N or prec")
        # The closest to identity is the local transport
        def norm_to_id(M):
            return (M - Matrix.identity(ZZ, M.nrows())).norm()
        M_local = min(isos, key=norm_to_id)
        M_total = M_local * M_total

    return M_total
```

**Limitations**:
- Requires QQ coefficients (or number field with explicit embedding) for RiemannSurface
- `symplectic_isomorphisms` uses LLL and can be slow (O(g^6) roughly)
- N must be large enough that consecutive fibers are "close" (no critical values between steps)
- For g=1 (elliptic curves) this is fast; for g≥3 it may be slow

## Approach 2: Ore algebra (Picard-Fuchs ODE) — dimension-independent

**Scope**: Any family of smooth hypersurfaces in projective space, or more generally any
family where the Gauss-Manin connection can be computed.

**Key tool**: `ore_algebra.analytic.monodromy.monodromy_matrices(dop, base)` in the
`ore_algebra` package (Kauers-Mezzarobba-van der Hoeven et al.).

```
from ore_algebra import DifferentialOperators
from ore_algebra.analytic.monodromy import monodromy_matrices

Dops, t, Dt = DifferentialOperators()
# dop = Picard-Fuchs ODE for the family
# e.g. for the Legendre family y^2 = x(x-1)(x-t):
dop = t*(1-t)*Dt^2 + (1-2*t)*Dt - (1/4)   # Gauss hypergeometric 2F1(1/2,1/2;1;t)
mats = monodromy_matrices(dop, base=1/2)
# Returns one matrix per singular point (t=0, t=1, t=∞)
```

**Strategy**:
1. Compute the Picard-Fuchs ODE L_t from f(x₁,...,xₙ, t) via Griffiths-Dwork reduction
   or automated differentiation-under-the-integral.
2. Feed L_t into `monodromy_matrices(L_t, basepoint)`.
3. The output is a list of matrices, one per singular point of L_t.

**Step 1 — computing the Picard-Fuchs ODE**:

This is the hard step. Options:
- **Griffiths-Dwork** (for smooth projective hypersurfaces): a classical algorithm,
  implemented in Macaulay2's `PeriodIntegrals` package but **not natively in Sage**.
- **Automatic differentiation of period integrals**: For f(x,t), differentiate
  ∫ ω/(f^k) with respect to t and reduce via the Griffiths reduction map. Algorithmic
  but requires a CAS with polynomial ideal operations. Macaulay2 or Singular can do this.
- **Lookup for standard families**: Picard-Fuchs operators for classical families
  (Legendre, Hesse, mirror quintic, etc.) are tabulated in the literature and in the
  `ore_algebra` examples.

**Installed state**:
- `ore_algebra` is a Sage optional package: `sage -pip install ore_algebra` or
  `pip install ore_algebra` in the sage venv.
- Check: `from ore_algebra.analytic.monodromy import monodromy_matrices`

**What `monodromy_matrices` does**:
- Computes the analytic continuation of the solutions of `dop` along a simple positive
  loop around each singular point, with certified (ball arithmetic) precision.
- Returns a numerical matrix (over CBF = ComplexBallField) for each singular point.
- Two algorithms: `algorithm='connect'` (default, faster) and `algorithm='loop'`
  (more robust).

**Monodromy group output**: If `dop` has singular points s₁,...,sₙ, then
`monodromy_matrices(dop, base)` returns matrices M₁,...,Mₙ where Mᵢ is the monodromy
around sᵢ. These satisfy M₁·M₂·...·Mₙ = Id (when the singular points include ∞) or
the appropriate fundamental group relation.

**Example**: Legendre family y² = x(x-1)(x-t), t ∈ ℂ \ {0,1}:

```python
from ore_algebra import DifferentialOperators
from ore_algebra.analytic.monodromy import monodromy_matrices

Dops, t, Dt = DifferentialOperators()
# Picard-Fuchs ODE: t(1-t)y'' + (1-2t)y' - (1/4)y = 0
# (hypergeometric 2F1(1/2,1/2;1;t), Euler-Gauss)
dop = 4*t*(1-t)*Dt^2 + 4*(1-2*t)*Dt - 1

mats = monodromy_matrices(dop, base=QQ(1,2))
# mats[0] = monodromy around t=0
# mats[1] = monodromy around t=1
# Together they generate the classical Γ(2) ⊂ SL(2,Z) monodromy representation
# M_0 = [[1,0],[2,1]], M_1 = [[1,-2],[0,1]] (up to conjugacy, in standard symplectic basis)
```

**Limitation**: Requires knowing the Picard-Fuchs ODE in advance; no direct automation
from a defining polynomial in Sage.

## Approach 3: Picard-Lefschetz formula (vanishing cycles, for Lefschetz-type degenerations)

**Scope**: Families where the degeneration at t=0 is a Lefschetz degeneration (one
ordinary double point formed, Milnor number 1).

**Statement (Picard-Lefschetz)**: If the degeneration is Lefschetz (single A₁ node),
the monodromy is a Dehn twist (for curves) or a Picard-Lefschetz reflection:

  M(γ) = γ ± ⟨γ, δ⟩·δ

where δ ∈ H_k(F_{t₀}, ℤ) is the vanishing cycle (the cycle that collapses to the
singular point as t→0), and ⟨·,·⟩ is the intersection form.

For curves (k=1): M is a symplectic transvection, the formula is
  M(v) = v + ⟨v, δ⟩·δ  (with sign depending on convention)

**Feasibility**: For each Lefschetz critical value, finding δ is a separate problem
(requires path-tracking in ℂ^n from the critical point to the basepoint). Not directly
available as a general Sage method, but implementable via:
1. Finding the critical values: roots of the discriminant Δ_f(t) = Res_x(f, ∂f/∂x)
2. Tracking the vanishing cycle via straight-line homotopy and numerical continuation
3. Expressing δ in terms of the standard homology basis of F_{t₀}

For **non-Lefschetz** degenerations (Milnor number μ > 1), the single monodromy M is
more complex but factors into μ Dehn twists (if a Morsification exists).

## Approach 4: Braid monodromy via sirocco (topological, for curve complements)

**Scope**: Curve arrangements in ℂ² — this gives monodromy of π₁(ℂ² \ C) as a braid,
NOT the H₁ monodromy of the fibers.

**Tool**: `sage.schemes.curves.plane_curve_arrangement.AffinePlaneCurveArrangements`
with the `sirocco` optional package.

```python
# needs sirocco
H.<x, y> = AffinePlaneCurveArrangements(QQ)
A = H(f1, f2, ...)
A.braid_monodromy()        # braids in B_n acting on the strands
A.fundamental_group()      # π₁(ℂ² \ A) as finitely presented group
```

**What it computes**: The Zariski-van Kampen monodromy as elements of the braid group
Bₙ (where n = degree of the curve in the y-variable). This describes how the roots
of f(x, y) in y permute and braid as x varies along a path in ℂ.

**Relationship to homological monodromy**: Via the Burau representation Bₙ → GL(n-1, ℤ[t,t⁻¹])
or the homological Burau representation, one can extract an approximation to the
H₁ monodromy. However, this conversion is non-trivial and requires knowing the
monodromy representation explicitly.

**Not recommended** as the primary approach for H₁ monodromy of a family, but
useful for:
- Confirming the topological type of the degeneration (number of critical values, etc.)
- Computing fundamental groups of fiber complements
- Extracting Lefschetz fibration data (vanishing cycles as braid elements)

## Approach 5: Numerical path-following via diamond loop

**Scope**: Completely general — f(x₁,...,xₙ, t) over a disc.

**Idea**: Rather than a smooth circular loop t(θ) = ε·e^{iθ}, use a diamond:

  t: ε → -i·ε → -ε → i·ε → ε   (four straight-line segments)

At each vertex, compute the period matrix (or period vector for a specific cycle)
by direct numerical integration. Track the analytic continuation step by step.

For curves: each segment defines a homotopy of Riemann surfaces. At each step, the
sheets (roots of f(·, t) in one variable) can be matched by proximity, giving a
permutation. Integrating ω along the transported paths gives the period matrix.

**Practical limitation**: This requires implementing analytic continuation of the
homology basis via numerical root-tracking and integration, essentially reimplementing
the core of the RiemannSurface machinery. The RiemannSurface approach (§1) is strictly
better for curves since it already does certified numerical integration.

For dimension ≥ 2 (higher-dimensional fibers), this approach would require integrating
periods of holomorphic forms over higher-dimensional cycles, which is substantially
harder — no standard Sage implementation exists.

## Recommended implementation plan

### For curves (dimension 1 fibers)

**Best approach: §1 (RiemannSurface chain)**, possibly combined with §3 for validation.

Steps:
1. Confirm the critical values of f(z,w,t) over t (roots of Res_z(f, ∂f/∂z)).
2. Choose a basepoint t₀ away from all critical values.
3. Choose N large enough that no critical value lies between consecutive points on the loop.
4. Compute RiemannSurface at N equidistant t-values; chain symplectic isomorphisms.
5. The resulting Sp(2g, ℤ) matrix is M.

Validation: For Lefschetz degenerations, verify that M = I + (·,δ)·δ as a transvection.

### For higher-dimensional fibers

**Best approach: §2 (Ore algebra)**, but requires the Picard-Fuchs ODE.

If the family is one of the standard ones (mirror families, complete intersections),
the Picard-Fuchs ODE is tabulated. Otherwise:
- Use Macaulay2's `PeriodIntegrals` package or Singular's `Gauss-Manin` routines
  to derive the Picard-Fuchs ODE, then pass to ore_algebra.
- This is not currently automated within Sage.

## Known explicit cases

### Legendre family y² = x(x-1)(x-t)

Picard-Fuchs: `4t(1-t)y'' + 4(1-2t)y' - y = 0` (hypergeometric 2F1(1/2,1/2;1;t))

Monodromy around t=0:  M₀ = [[1, 0], [-2, 1]]  (transvection; δ is the cycle collapsing)
Monodromy around t=1:  M₁ = [[1, 2], [0, 1]]   (conjugate transvection)
Monodromy around t=∞:  M∞ = (M₀·M₁)⁻¹ = [[-1, -2], [2, 3]]

Together M₀, M₁ generate Γ(2) ⊂ SL(2,ℤ) (the principal congruence subgroup of level 2).

### Weierstrass family y² = x³ - t (j=0 family)

Picard-Fuchs: `27t·y'' + 27·y' + y = 0` (hypergeometric 2F1(1/6,5/6;1;t/t_0) after change of variables)

Single singular point at t=0 (cuspidal degeneration). Monodromy is:
  M = [[1, 0], [1, 1]]  (unipotent, N = M-I, N²=0) — Type II in Kulikov classification

The matrix M is a single Dehn twist; the vanishing cycle is the cycle that collapses
to the cusp (a nonseparating cycle). Since N² = 0, this confirms the cuspidal fiber is
type I₁ in the Kodaira classification.

### Hesse pencil x³+y³+z³-3t·xyz = 0

Singular at t = 1 and t = ∞ (three values t = 1, ω, ω² for ω = e^{2πi/3}).
Monodromy around t=1 is a Dehn twist (Lefschetz node). The global monodromy group is
commensurable with SL(2,ℤ) (elliptic surface of Kodaira type IV reduction).
