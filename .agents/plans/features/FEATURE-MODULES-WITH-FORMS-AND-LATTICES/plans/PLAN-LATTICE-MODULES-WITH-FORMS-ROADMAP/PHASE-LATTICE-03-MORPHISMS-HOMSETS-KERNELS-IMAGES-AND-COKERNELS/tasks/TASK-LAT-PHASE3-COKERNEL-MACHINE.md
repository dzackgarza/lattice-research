## Grounded Implementation Contract

- Source anchors:
  - `.agents/skills/lattice-redesign/references/category-abc-spec.md`
  - `.agents/skills/lattice-redesign/references/lattice-interface-style-guide.md`
  - `theory/foundations/bilinear-forms-duals-morphisms.md`
  - `category_specs/forms/docs/MAPPING.md`
  - `category_specs/lattices/docs/MAPPING.md`
- Ambient object: for a form-preserving morphism `f : M -> N` in `ModulesWithForms(R).Bilinear()` or a sourced symmetric refinement, `f.cokernel()` returns the actual quotient object `Q = N / im(f)` in the formed-module hierarchy, not a raw presentation matrix or bare FGP quotient.
- Descended-form stage:
  - first compute the module quotient `Q = coker(f)` in the target fiber;
  - compute the first coefficient quotient `N_0 = coker(h)` for the coefficient-map part of the morphism data;
  - let `E = im(f) ⊆ N`; the descended coefficient module is
    `N_0 / <beta_N(E · N)>`, i.e. quotient by the submodule generated by the cross-terms coming from one image factor and one arbitrary codomain factor;
  - the bilinear/symmetric form on `N` descends uniquely to `bar(beta) : Sym^2(Q) -> N_0 / <beta_N(E · N)>`.
- Codomain contract:
  - integral-to-rational descent is the critical sourced case: for `L -> L^#`, the coefficient map is `ZZ -> QQ`, so the first coefficient quotient is `QQ/ZZ`;
  - because `beta_{L^#}(L, L^#) ⊆ ZZ`, the cross-term image is already zero in `QQ/ZZ`, so no further quotient is taken in the discriminant-form path;
  - more generally, the returned formed object must advertise the quotient-valued codomain forced by the coefficient cokernel and cross-term quotient, rather than guessing from wrapper class names.
- Boundary:
  - the public result is the cokernel formed object with descended form data;
  - matrix identities are backend verification of well-defined descent, not the public definition of the cokernel.

## Acceptance Criteria

- [ ] `cokernel()` returns a formed quotient object in the same categorical family as the codomain, with quotient generators and invariants coming from the underlying quotient construction.
- [ ] The descended coefficient codomain is computed by `coker(h)` plus the cross-term quotient `<beta_N(im(f) · N)>`; it is not modeled as a quotient of the module carrier itself.
- [ ] The discriminant path `L -> L^#` produces `L^#/L` with form values in `QQ/ZZ`, and the implementation explicitly treats the cross-term quotient as already zero in that case.
- [ ] Free/torsion/integral/rational promotion of the cokernel object follows the quotient data actually produced, including torsion quotient outputs.

## Dependencies And Boundaries

Execute within `src/lattices/morphisms/bilinear.py` and keep the public surface quotient-first: quotient object, descended form, and codomain quotient. Do not replace the categorical cokernel by a matrix-only or ambient-space artifact.
