# Vinberg Algorithm

This skill routes work on Vinberg's algorithm and hyperbolic reflection-group computations.

## Canonical source

Read `theory/backends/vinberg-algorithm.md` before changing code, tests, benchmarks, or task cards related to Vinberg's algorithm.

## Boundaries

- The target group is `W(L)`, the full hyperbolic reflection group generated by roots of the lattice.
- The control vector selects a Weyl chamber; it does not define a different group.
- Use exact arithmetic only.
- Treat root enumeration as a proof-sensitive algorithmic task. Bounded search without a termination proof is not evidence.
- Compare against reference implementations only after reading their source-level behavior: VinbergsAlgorithmNF, AlVin, and vinal.
