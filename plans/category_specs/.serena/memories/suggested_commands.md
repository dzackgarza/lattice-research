# Suggested Commands for Category Specs

## Task Automation
The project uses `just` for running tasks.

- `just`: List available recipes.
- `just smoke`: Run smoke tests for sets, rings, and modules.
- `just test`: Run all tests, including regression tests and new specification tests.

## Development Utilities
- `sage <file>.sage`: Execute a SageMath script.
- `just _clean-sage-artifacts`: (Private) Clean up `.sage.py` files generated by Sage.

## Git Workflow
Follow the standard git guidelines as per `GEMINI.md`. Always checkpoint before editing.
