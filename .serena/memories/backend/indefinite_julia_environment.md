`Indefinite.jl` on Julia 1.6.7 works in this environment only if GAP is isolated from the user `~/.gap/pkg/JuliaInterface` tree. The failure mode without isolation is `_JuliaGetMainModule` from `/home/dzack/.gap/pkg/JuliaInterface/gap/JuliaInterface.gi`. Setting `ENV["HOME"]` inside the Julia process before `using Indefinite` avoids that collision while still using the normal Julia depot for packages and precompile cache.
